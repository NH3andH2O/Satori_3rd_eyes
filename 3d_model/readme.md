# 机械觉之瞳模型

## 其他作者

-   **3rd_eyes:** by 牧鈴華SUZUKA，（[项目地址](https://www.bilibili.com/video/BV1rN1gYJE3K)）

## 如何使用

把所有的`.stl`文件使用3d打印机打印出来，然后对照`STR-rc.prt`来安装

## 注意事项

-   **舵机：** 使用 MG90S 180度的舵机，需要先90度居中，在安装
    1.   使用`tools\servo_set`让舵机处于居中位置。
    2.   按照下图安装舵臂和齿轮：\
           <img src="https://github.com/user-attachments/assets/966a090c-c51c-4c40-b57b-3a016ed3d949" width="300" />\
        上眼皮舵臂安装位置

            <img src="https://github.com/user-attachments/assets/13863228-87b3-4ce6-bbb7-370c8e705013" width="300" />\
         眼球舵臂安装位置，应该使舵臂与舵机处于垂直状态

            <img src="https://github.com/user-attachments/assets/527a5b8f-8182-4cc5-b2bd-1d44201bb876" width="300" />\
         下眼皮齿轮安装位置，你应该先调节齿轮轴（黄色区域）的方向，使杆子缺口方向朝向正外面（如蓝色符号所示），在与舵机上面的齿轮啮合。
-   **关于pupil_GC9A01.prt：** 此为`pupil.prt`中间开槽版本，中间可以放入厚度`0.5mm`，直径`26.8mm`的圆形透明亚克力板（淘宝可以定制）
-   **关于heartShaped_dowm.prt：** 底面有开孔，可以使用轧带固定在头饰上面。
