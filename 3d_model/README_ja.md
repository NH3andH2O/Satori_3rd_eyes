# 機械式サードアイのモデル

## その他の作者

- **3rd_eyes：** 牧鈴華SUZUKA（[プロジェクトページ](https://www.bilibili.com/video/BV1rN1gYJE3K)）

## 使用方法

すべての `.stl` ファイルを 3D プリンターで出力し、`STR-rc.prt` を参照して組み立ててください。

## 注意事項

- **サーボ：** MG90S 180 度サーボを使用します。取り付ける前に 90 度の中央位置に合わせてください。
  1. プログラムを使用してサーボを中央位置に移動します。
     > [!TIP]
     > メインファームウェアを書き込んだ後、Web インターフェースのサードアイ調整ページを開き、3 個のサーボを 90 度に設定してからサーボホーンとギアを取り付けることもできます。
  2. 次の図に従ってサーボホーンとギアを取り付けます。  
     <img src="https://github.com/user-attachments/assets/966a090c-c51c-4c40-b57b-3a016ed3d949" width="300" />  \
     上まぶた用サーボホーンの取り付け位置

     <img src="https://github.com/user-attachments/assets/13863228-87b3-4ce6-bbb7-370c8e705013" width="300" />  \
     眼球用サーボホーンの取り付け位置。サーボホーンがサーボに対して垂直になるようにしてください。

     <img src="https://github.com/user-attachments/assets/527a5b8f-8182-4cc5-b2bd-1d44201bb876" width="300" />  \
     下まぶた用ギアの取り付け位置。最初にギア軸（黄色の領域）の向きを調整し、ロッドの切り欠きが青い印のように真外側を向くようにしてから、サーボ側のギアとかみ合わせてください。
- **`pupil_GC9A01.prt` について：** `pupil.prt` の中央に溝を設けたバージョンです。厚さ `0.5 mm`、直径 `26.8 mm` の円形透明アクリル板を中央に取り付けられます。
- **`heartShaped_dowm.prt` について：** 底面に取り付け穴があり、結束バンドで髪飾りに固定できます。
